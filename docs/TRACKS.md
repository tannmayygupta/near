# Track proof map

Judges (human and AI) check that every claimed track has a real integration in the code. A track is claimed only if its row has real paths and a command that works. Status values: `verified on testnet` (explorer-linked, recorded in `data/demo-run/*.json`), `quoted only` (live API quotes, no money moved), `designed` (code present, not proven). Nothing was run on mainnet. Full claim-by-claim table: [CLAIMS.md](CLAIMS.md).

| Track | Claim in one line | What a judge sees | Proof paths | Command to verify | Status |
|---|---|---|---|---|---|
| Social Money (`social`) | A Sputnik DAO decides; members vote once and the agent only acts inside that vote; treasurer reputation is earned on-chain and mirrored to near.social | proposals `create_mandate` + funding `Transfer`, 2-of-3 votes, trust score, a DAO-voted near.social post | `src/near/sputnik.ts`, `src/near/social.ts`, `worker/guards.ts`, `contracts/mandate/src/lib.rs`, dashboard `/votes` `/reputation` | `npm run demo` (offline story), `data/demo-run/run.json` (`txs`, `proposals`) | verified on testnet |
| Autonomous Business (`business`) | After the funding vote no human acts until the anchored report; a DAO cancel is the kill switch; a killed worker resumes without double-swapping | sells in price-floored chunks, pays contributors and a fee, returns leftovers, anchors the report | `worker/executor.ts`, `worker/adapters/ref-testnet.ts`, `scripts/testnet/e2e-restart.ts` | `npm run e2e:custody` (37/37), `npm run e2e:restart` (13/13), `npm run demo` | verified on testnet |
| AI Security & Defense (`security`) | Three independent layers: the NEAR protocol scopes the worker's key, an OutLayer wallet policy is written per mandate, our contract and executor enforce budget, window, token and destination | six red-team attacks each name the layer that stopped them; protocol refusals of an over-reaching key | `scripts/testnet/scoped-key.ts`, `worker/adapters/mandate-policy.ts`, `worker/guards.ts`, `worker/redteam.ts`, `docs/CUSTODY.md` | `data/testnet-scoped-key.json`, `data/demo-run/custody-run.json` (`protocolScope`, `layerA`, `redteam`), dashboard `/custody` `/redteam` | verified on testnet (limits stated: OutLayer's policy does not check token recipients or amounts) |
| Privacy & Private AI (`privacy`) | The mandate is drafted and the settlement summarised inside a NEAR AI Cloud TEE; every answer is signed and attested and re-verified independently | signed completions, attestation with a fresh nonce, the verifier's checks | `src/near/ai.ts`, `src/engine/parser.ts`, `src/verify/` | `npm run verify` | verified (AI part only; hidden execution NOT claimed, mainnet-only) |
| Real-World Money (`realworld`) | Real token payouts to named accounts, a service fee, leftovers back to the DAO, balances checked before and after, accountant CSV | `/ledger` and `/report` with a transaction link on every row | `worker/adapters/ref-testnet.ts`, `src/engine/settlement.ts`, `app/app/ledger` | `data/demo-run/custody-run.json` (`real.payouts`, `real.balanceDeltas`) | verified on testnet (play money; no cross-chain payouts) |
| Open Innovation (`open`) | Sealed mandates: only `sha256(salt \| terms)` and the budget are public while the agent trades; terms are revealed on-chain after settlement and independently verified | `terms_json = null` on chain while executing; verifier rejects five tampering cases | `src/verify/sealed.ts`, `worker/auth.ts`, `docs/SEALED.md` | `npm run verify` (21 checks), `npm run e2e:sealed` (37/37) | verified on testnet (the operator can read sealed terms) |
| Unstoppable DeFi (`defi`) | Real DEX execution under an on-chain mandate with a price floor on every chunk; cross-chain Intents routes live-quoted | `/routes` with live 1Click dry quotes; `live-dryrun` decision path | `src/near/routes.ts`, `src/near/intents.ts`, `worker/adapters/live-dryrun.ts`, `docs/DEFI.md` | `data/demo-run/mainnet-readonly.json`, `data/demo-run/mainnet-dryrun-decision.json` | verified on testnet for swaps; **quoted only** for Intents (weakest claim) |
