# Track proof map

Seven tracks, each backed by a working integration, a reproducible command and recorded evidence. **Status vocabulary:** *validated on public testnet* means a recorded run with explorer-linked transactions in `data/demo-run/`; *live-quoted* means real API quotes with no funds moved; *mainnet run: not executed* is stated once per track so the environment of every claim is unambiguous. Claim-by-claim detail: [CLAIMS.md](CLAIMS.md). What a mainnet run would add, track by track: [MAINNET-CLAIMS-GATE.md](MAINNET-CLAIMS-GATE.md).

| Track | Feature implemented | Value | Demonstrated workflow (public testnet) | Evidence and commands | Status |
|---|---|---|---|---|---|
| **Social Money** (`social`) | A Sputnik DAO decides; members vote once and the agent can act only inside that vote. ## Beyond the tracks
* **Reproducible contract build:** a rebuild in the pinned image is byte-for-byte identical to the committed wasm and to the deployed testnet contract (`npm run verify:contract`; [MAINNET-RELEASE-AUDIT.md](MAINNET-RELEASE-AUDIT.md)).
* **Mainnet deployment kit:** atomic deploy-and-initialise, read-only preflight, on-chain verification and a contract test script, rehearsed on testnet ([MAINNET.md](MAINNET.md)); live status at `/mainnet`.
* **Not part of this build:** swarms, agent economies, NFTs, games and memecoins.
